# 🚀 Быстрый старт

## Минимальные шаги для запуска приложения

### 1. Установите зависимости

Откройте два терминала в корневой папке проекта.

**Терминал 1 - Backend:**
```bash
cd backend
npm install
```

**Терминал 2 - Frontend:**
```bash
cd frontend
npm install
```

### 2. Запустите приложение

**Терминал 1 - Запуск Backend сервера:**
```bash
cd backend
npm start
```
✅ Backend запущен на http://localhost:5000

**Терминал 2 - Запуск Frontend:**
```bash
cd frontend
npm run dev
```
✅ Приложение доступно на http://localhost:3000

### 3. Откройте браузер

Перейдите по адресу: http://localhost:3000

## 🔧 Устранение проблем

**Если порт 5000 занят:**
```bash
# В backend/.env создайте файл и укажите:
PORT=5001
```

**Если порт 3000 занят:**
Vite автоматически предложит другой порт (3001, 3002 и т.д.)

**Если не установлены зависимости:**
Убедитесь, что у вас установлен Node.js версии 16+
```bash
node --version
npm --version
```
