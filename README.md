# 📝 Notes App - Приложение для заметок

Современное полнофункциональное веб-приложение для создания и управления заметками с красивым интерфейсом и удобными функциями.

## 📋 Описание

Notes App — это полноценное fullstack приложение, состоящее из React frontend, Node.js/Express backend и SQLite базы данных. Приложение позволяет создавать, редактировать, удалять и организовывать заметки с различными цветами и возможностью закрепления важных заметок.

## 🚀 Технологии

### Frontend
- **React 18** - библиотека для создания пользовательских интерфейсов
- **React Hooks** - useState, useEffect для управления состоянием
- **Vite** - современный инструмент сборки
- **CSS3** - стилизация без UI-фреймворков

### Backend
- **Node.js** - серверная платформа
- **Express** - веб-фреймворк
- **Better-SQLite3** - быстрая синхронная SQLite база данных
- **CORS** - поддержка кросс-доменных запросов

### База данных
- **SQLite** - легкая реляционная база данных
- Схема с таблицей notes (id, title, content, color, isPinned, createdAt, updatedAt)

## ✨ Функциональность

### Основные функции
- ✅ **Создание заметок** - добавление новых заметок с заголовком и содержимым

- ✅ **Удаление заметок** - удаление с подтверждением в модальном окне
- ✅ **Поиск** - поиск по заголовку и содержимому заметок

- ✅ **Сортировка** - по дате создания, изменения или заголовку
- ✅ **Сохранение данных** - все заметки сохраняются в SQLite базе данных

## 🛠️ Установка и запуск

### Предварительные требования
- Node.js версии 16 или выше
- npm версии 7 или выше

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/zainabmambetkulovva/Notes-app.git
cd "Notes app"
```

### Шаг 2: Установка зависимостей

#### Backend
```bash
cd backend
npm install
```

#### Frontend
```bash
cd ../frontend
npm install
```

### Шаг 3: Запуск приложения

#### Запуск Backend сервера
```bash
cd backend
npm start
```
Сервер запустится на http://localhost:5000

#### Запуск Frontend (в отдельном терминале)
```bash
cd frontend
npm run dev
```
Приложение будет доступно на http://localhost:3000

### Альтернативный способ (для разработки)

Backend с автоперезагрузкой:
```bash
cd backend
npm run dev
```

## 🔌 API Endpoints

### GET /api/notes
Получить все заметки с возможностью поиска и сортировки
- Query параметры:
  - `search` - поисковый запрос (опционально)
  - `sortBy` - тип сортировки: createdAt, updatedAt, title (опционально)
- Ответ: массив заметок

### GET /api/notes/:id
Получить конкретную заметку по ID
- Параметры: id заметки
- Ответ: объект заметки или 404

### POST /api/notes
Создать новую заметку
- Body: `{ title, content, color, isPinned }`
- Ответ: созданная заметка со статусом 201

### PUT /api/notes/:id
Обновить заметку
- Параметры: id заметки
- Body: `{ title, content, color, isPinned }` (все поля опциональны)
- Ответ: обновленная заметка

### DELETE /api/notes/:id
Удалить заметку
- Параметры: id заметки
- Ответ: сообщение об успешном удалении

## 🗄️ База данных

### Схема таблицы notes
```sql
CREATE TABLE notes (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  content TEXT NOT NULL,
  color TEXT DEFAULT '#ffffff',
  isPinned INTEGER DEFAULT 0,
  createdAt TEXT NOT NULL,
  updatedAt TEXT NOT NULL
)
```

База данных создается автоматически при первом запуске backend сервера.

## 🧪 Проверка работоспособности

После запуска приложения проверьте следующие функции:

1. **Создание заметки**
   - Нажмите "Создать заметку"
   - Заполните заголовок и содержимое
   - Выберите цвет
   - Отметьте "Закрепить заметку" (опционально)
   - Нажмите "Создать заметку"

2. **Редактирование заметки**
   - Нажмите на иконку редактирования (✏️) на карточке заметки
   - Измените данные
   - Нажмите "Сохранить изменения"

3. **Удаление заметки**
   - Нажмите на иконку удаления (🗑️)
   - Подтвердите удаление в диалоговом окне

4. **Поиск**
   - Введите текст в поисковую строку
   - Заметки фильтруются в реальном времени

5. **Закрепление**
   - Нажмите на иконку закрепления (📍/📌)
   - Закрепленные заметки отображаются вверху

6. **Сортировка**
   - Выберите тип сортировки из выпадающего списка
   - Заметки пересортируются

7. **Сохранение данных**
   - Создайте несколько заметок
   - Перезагрузите страницу
   - Убедитесь, что все заметки сохранились
